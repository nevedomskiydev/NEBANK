# NEBANK — установка и перезапуск

Готовые команды для сервера **104.194.143.122** (Ubuntu 24.04, Лондон).
Mini App будет доступен по адресу **https://104-194-143-122.sslip.io**, бот — **@nebanknebot**.

Единственное, что нужно вставить своё — **токен бота** из @BotFather (одна строка).

---

## Шаг 1. Получить токен бота (один раз)

1. Откройте Telegram, напишите **@BotFather**.
2. Команда `/mybots` → выберите **@nebanknebot** → **API Token** (или `/token`).
3. Скопируйте строку вида `8123456789:AAH...` — это и есть `BOT_TOKEN`.

> Больше в BotFather ничего настраивать не нужно: кнопку меню с Mini App
> бот выставляет себе сам при запуске.

---

## Шаг 2. Загрузить проект на сервер

С вашего компьютера (где лежит `nebank.zip`):

```
scp nebank.zip root@104.194.143.122:/root/nebank.zip
```

Пароль сервера: тот, что выдан в панели (root).

---

## Шаг 3. Установить (чистит сервер и поднимает всё заново)

Подключитесь к серверу и выполните. Замените только токен в кавычках:

```
ssh root@104.194.143.122
apt-get update -y && apt-get install -y unzip
rm -rf /opt/nebank && mkdir -p /opt/nebank
unzip -o /root/nebank.zip -d /opt/nebank
cd /opt/nebank
BOT_TOKEN='ВСТАВЬТЕ_СЮДА_ТОКЕН_ОТ_BOTFATHER' bash deploy/install.sh
```

Первый запуск занимает несколько минут (сборка образа, получение HTTPS-сертификата).
В конце вы увидите `Done. NEBANK is live.`

Откройте **@nebanknebot** в Telegram, нажмите **Start** — и кнопку меню **NEBANK**.

---

## Полезные команды

```
cd /opt/nebank

# логи приложения
docker compose logs -f app

# статус контейнеров
docker compose ps

# перезапуск без пересборки (например, после правки .env)
bash deploy/restart.sh

# пересобрать после обновления кода (база сохраняется)
bash deploy/update.sh

# полный сброс с очисткой базы данных
BOT_TOKEN='ВАШ_ТОКЕН' bash deploy/install.sh --wipe
```

## Что включено и что опционально

- **Работает сразу, без ключей:** бот, Mini App, реальные курсы валют и крипты,
  разбор трат текстом, банковские СМС, фото-чеки и QR (Tesseract + ZBar),
  отчёты, бюджеты, цели, привычки, подписки, достижения, оплата Telegram Stars.
- **Опционально (улучшает распознавание):** голосовой ввод и LLM-подсказки.
  Для голоса задайте `WHISPER_API_KEY` в `.env` (любой OpenAI-совместимый ключ)
  и `bash deploy/restart.sh`. Без ключа бот вежливо просит ввести текстом —
  «чуши» не выдаёт.

Курсы — только реальные данные (CoinGecko + Frankfurter). Ничего выдуманного.
