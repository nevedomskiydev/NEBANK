# NEBANK

**Личный финансовый помощник в Telegram — бот + Mini App.**
Премиальный светлый интерфейс в духе iOS. Только реальные данные.

---

NEBANK — финтех-продукт без привязки к реальному банку: вы записываете траты и
доходы как удобно (текст, голос, фото чека/QR, пересланная банковская СМС, ссылка
на крипто-транзакцию), а продукт превращает это в аккуратную картину ваших денег.

- **Бот (@nebanknebot)** — быстрый слой: записать, посмотреть отчёт, поделиться.
- **Mini App** — главный дом: дашборд, история, бюджеты, цели, привычки, курсы.

Установка одной командой — см. **[INSTALL.md](INSTALL.md)**.

## Возможности

| Раздел | Что делает |
|---|---|
| Ввод | Текст · голос (RU/EN) · фото чека/QR/скрин · банковская СМС · крипто-ссылка |
| Разбор | Мультизапись («кофе 200, такси 350»), числа словами и дроби, любые форматы дат (день-первым), пересчёт в базовую валюту по курсу дня |
| Дашборд | Баланс/доход/расход, фирменная кольцевая диаграмма с проваливанием в категорию, тренд, последние операции |
| История | Полная история с фильтрами, поиском, редактированием — данные не теряются |
| Бюджеты | Лимит на категорию, прогресс, индикация перерасхода, правка тапом |
| Привычки | «Отказ от вредных платежей»: сэкономлено и дней без срыва, шеринг |
| Подписки | Управление + календарь, авто-определение регулярных платежей, напоминания за 3 и 1 день |
| Инсайты | Этот месяц против прошлого + прогноз до конца месяца |
| Курсы | Реальные курсы крипты и валют, зелёно/красная история, конвертер |
| Достижения | 12 прогрессивных достижений на реальных данных |
| Цели · Заначка | Накопления с прогрессом · округление трат в виртуальную заначку |
| Совместный бюджет | Общий бюджет с близкими + встроенная рефералка по ссылке |
| Монетизация | Premium через Telegram Stars (~250 Stars/мес) |

Языки — русский и английский везде, включая меню команд бота.
Дизайн — строго светлый, премиальный, без эмодзи.

## Архитектура

```
Telegram ──webhook──┐
                    ▼
        ┌───────────────────────┐        ┌──────────────┐
  HTTPS │  FastAPI (app)        │◀──────▶│ PostgreSQL   │
 (Caddy)│  · Mini App REST API  │        └──────────────┘
   ▲    │  · aiogram bot        │
   │    │  · APScheduler        │   реальные курсы: CoinGecko + Frankfurter
 браузер│  · статика Mini App   │   OCR: Tesseract + ZBar   голос: Whisper (опц.)
 /бот   └───────────────────────┘
```

- **backend/** — Python 3.11, FastAPI, aiogram 3, SQLAlchemy (async), APScheduler.
- **miniapp/** — React + TypeScript + Vite, кастомный дизайн-система и SVG-графики.
- **deploy/** — Docker Compose, Caddy (авто-HTTPS), один скрипт установки.

## Технологический стек

Backend: FastAPI · aiogram · SQLAlchemy 2 (asyncpg) · APScheduler · matplotlib ·
Pillow · openpyxl · Tesseract · ZBar.
Frontend: React 18 · TypeScript · Vite · Telegram WebApp SDK.
Инфра: Docker Compose · PostgreSQL 16 · Caddy 2 (Let's Encrypt).

## Разработка

```
# backend
cd backend && python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
DATABASE_URL=sqlite+aiosqlite:///./dev.db BOT_TOKEN= uvicorn app.main:app --reload

# miniapp
cd miniapp && npm install && npm run dev
```

Соответствие требованиям ТЗ — в **[docs/REQUIREMENTS.md](docs/REQUIREMENTS.md)**.

## Приватность

Без подключения к реальному банку. Ввод ручной и полуавтоматический.
Курсы запрашиваются у публичных источников; никаких выдуманных значений.
